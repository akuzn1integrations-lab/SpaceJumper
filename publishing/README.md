# Материалы для публикации SpaceJumper

- `texts/ru.md`, `texts/en.md`: карточка игры и инструкции на двух языках.
- `review/audit.md`: результаты проверки и обязательные ручные шаги.
- `images/`: исходные векторные промоматериалы SVG; перед загрузкой в Консоль экспортируйте в нужный PNG/JPEG формат и проверьте актуальные размеры.

**Важно:** промоизображения — художественные иллюстрации, а не скриншоты геймплея. Реальные скриншоты и при необходимости видео необходимо записать из запущенной игры.

Пакет исходных PNG-иллюстраций также подготовлен отдельно в разговоре, но бинарные PNG-файлы не перенесены в GitHub этим коммитом. В репозитории находятся SVG-исходники.
