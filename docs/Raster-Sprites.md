# Детализированный растровый космонавт

## Подключение

В `sprites.js` добавлена загрузка `assets/sprites/astronaut-chibi-atlas.webp`. Это прозрачный растровый атлас 512×512 пикселей с 16 кадрами (4×4). При отсутствии изображения автоматически используется ранее подключённый SVG-атлас, поэтому игра остаётся работоспособной.

## Важно: загрузка бинарного файла

GitHub-коннектор, доступный в этом чате, не принимает локальные бинарные файлы через обычную операцию создания текстового файла. Растровый файл подготовлен отдельно; его необходимо загрузить в репозиторий в каталог `assets/sprites/`, сохранив имя `astronaut-chibi-atlas.webp`. После этого игра автоматически переключится на новый спрайт.

## Анимация

- 0–3: фронтальные позы;
- 4–7: бег в три четверти;
- 8–11: боковой бег/ожидание;
- 12: взлёт;
- 13: полёт с реактивным следом;
- 14: приземление;
- 15: повреждение.

Направление запоминается и сохраняется после отпускания кнопки. Для движения влево боковые кадры зеркально отражаются. Режим уменьшенной анимации использует стабильные кадры.

## Проверка

Проверить, что запрос `assets/sprites/astronaut-chibi-atlas.webp` возвращает 200, а не 404. Затем запустить игру и проверить повороты, прыжок, приземление, повреждение и мобильное управление. Временная SVG-графика должна исчезнуть после успешной загрузки файла.

Это первый растровый набор персонажа; остальные объекты пока используют существующий SVG-атлас.
