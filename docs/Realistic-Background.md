# Реалистичный растровый фон

В `backdrop.js` добавлена загрузка готового WebP-изображения вместо программной генерации.

**Осталось добавить бинарный файл в репозиторий** по точному пути:

`assets/background/spacejumper-background.webp`

Файл подготовлен в текущем диалоге ChatGPT как `spacejumper-background.webp` (около 125 КБ, исходная композиция 941×1672). Загрузите его через GitHub → Add file → Upload files, сохранив указанный путь. После этого игра автоматически начнёт использовать реалистичное изображение. До появления файла используется прежний процедурный фон — это намеренное безопасное поведение.

`scripts/build.ps1` уже копирует каталог `assets` в ZIP. Растровый фон отрисовывается под игровыми платформами и HUD, с лёгким затемнением для читаемости опасностей. Для режима уменьшения анимаций дополнительные движущиеся частицы отключены.

Проверить после загрузки:
1. Запустить игру, открыть DevTools → Network и убедиться, что `assets/background/spacejumper-background.webp` возвращает HTTP 200.
2. Проверить изображение на телефоне и ПК: планета снизу слева, галактика сверху справа.
3. Убедиться, что платформы, лазеры и кристаллы хорошо видны на фоне.
4. Собрать архив и убедиться, что файл WebP присутствует в `assets/background/`.

Растровое изображение не копирует игровой интерфейс: HUD, персонаж, платформы и опасности по-прежнему рисуются движком.
